# UI:習慣(H2)

習慣視圖、圈圈、樂觀計數、中欄小區塊、焦點。資料形狀與領域規則見 `docs/data-model.md`,決策理由見 `docs/decisions.md` §6b。

## 習慣視圖(`?view=habits&habit=ID`)

中欄是 `HabitList`:頂端新增列(`NewHabitForm`,同任務新增列:名稱 trim 後空白不送、成功才清空、焦點留在輸入框;用每天 1 次建立,成功後選取它),下方是進行中的習慣(含已滿額),底部「已停止」區塊。列上:名稱、本週期進度(「本週 2/4」)、streak(紀錄型不顯示)、圈圈或數字;已停止的列不畫圈圈。

右欄是 `HabitDetail`(`key={habit.id}`):名稱(失焦即存)、頻率(點選即存)、目標次數(失焦即存,留空 = 紀錄型)、全期累計與 streak、停止/重新開始、最底部刪除(ConfirmDialog,文案寫明一併刪掉 N 筆紀錄)。

`habit` 參數指到不存在的習慣時由 effect 清掉;其他視圖不讀這個參數。

## 圈圈

`HabitCircles`,習慣視圖與中欄共用;畫面模型是 `src/lib/habitView.ts` 的 `circleModel`。

- 有目標且 target <= 6 才用圈圈;target > 6 顯示 `count/target` 加 −/+;紀錄型顯示次數加 +。count 0 時的 − 不動作,用 `aria-disabled`,不用 `disabled`。
- 四種狀態:已勾(實心深色)、下一顆(空心、邊框明顯)、尚未輪到(空心淡色)、超額(接在目標之後,只有外框)。深淺編碼已勾與未勾,不是位置。
- 可點的只有第 count+1 顆(+1)與第 count 顆(-1)。滿額收合成大勾加一顆小圈圈:沒有超額時點大勾退一步(展開回圈圈);有超額時大勾不可點(`aria-disabled`、沒有 pointer),從最後一顆超額圈圈或 +N(超額超過 3 顆)一顆一顆退;小圈圈超額 +1。超額時右邊顯示 `6/4`。
- 整排一個 tab stop(`role="group"`,`aria-label` 帶名稱與次數),圈圈本身是 span、不可聚焦。Space/Enter 送 +1,←/− 送 -1。點圈圈不選取所在的列。

## 計數的樂觀更新

`ThreeColumnLayout` 的 `stepHabit`。新值由 `stepCounts` 從覆寫值(沒有就用伺服器的 `periodCounts`)算出,同一個結果同時顯示與送出(`PUT …/logs?date=` 絕對值)。+1 記在今天;-1 作用在本週期最近有紀錄的那天。覆寫值存在 `countOverridesRef`(同步)與 state 複本(給畫面);每個習慣記排隊中的 PUT 數,全部送完、重抓回來後才清掉。失敗時立刻清掉覆寫值並重抓,錯誤訊息(`habitCountMessage`,明講「次數已還原」)顯示在中欄新增列下方。

其他習慣寫入(新增、PATCH、停止、刪除)走 `mutateHabit`,不做樂觀更新。所有習慣寫入與任務共用同一條佇列。

## 中欄小區塊

`HabitBlock`,只在「今天」與「全部未完成」。由 `TaskList` 的 `habitBlock` prop 畫在新增列與錯誤之後、任務清單之前。

只列進行中、有目標、本週期未滿額的習慣;停止中與紀錄型不列,也不算進總數。只要有進行中、有目標的習慣就出現,全部滿額時保留標題列並顯示「本週期的習慣都完成了」;一個都沒有才整個不出現。

可收合,預設展開,收合後標題顯示「習慣 已滿額/總數」;收合狀態存 localStorage(兩個視圖共用一個 key),在 effect 裡讀。

滿額時先顯示大勾 `FULL_HOLD_MS`(400ms),期間退回就取消離場;之後照任務列的退場方式淡出並收起高度(`--motion-duration`、`--motion-easing`),減少動態時直接移除。

## 焦點

中欄小區塊的列離場前(變成 inert 之前),焦點若在那一列裡就移到下一列的圈圈 → 上一列的圈圈 → 區塊的收合鈕。停止/重新開始是同一個按鈕原地換文字,焦點留在它上面,中欄的列移到「已停止」不動中欄焦點。刪除習慣後焦點落到遞補的列(同一索引 → 上一列 → 中欄容器,`restoreHabitFocus`)。習慣的列不帶 `data-task-id`,任務的焦點遞補看不到它們。

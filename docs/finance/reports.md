# 報表

`reports` 模組只讀。交易一律經過 `ledger/list.ts` 的 `listTransactions` 取得,篩選規則跟交易清單是同一份
(見 `docs/finance/transactions.md`);報表只負責加總。回傳的形狀在 `lib/reports.ts`。

## 期間摘要

程式在 `server/reports/summary.ts`(`summarizeTransactions`),API 是 `GET /api/finance/reports/summary`,
網址參數跟交易清單相同(`cursor`、`limit`、`order` 不影響結果)。畫面在交易清單上方(`components/TransactionSummary.tsx`):
一列合計,「分類明細」展開各分類(展開與否記在瀏覽器的 localStorage)。新增、編輯、刪除交易之後重新取。

- **加總的對象**:符合條件的交易裡,記在支出、收入分類的分錄。資產、負債、權益的分錄不算,所以轉帳、換匯、期初餘額本身不算;
  它們帶的手續費(支出分類)算進支出。
- **支出**:支出分類的分錄合計,借方為正;退款(貸方)沖減。**收入**:收入分類的分錄合計取負號。**淨額** = 收入 − 支出。
- **固定 / 變動**:交易配對到週期項目(`scheduled_id` 不是空的)的支出是固定,其餘是變動。收入不分。
- **有分類篩選時**:只加總那個分類(上層含子分類)的分錄;拆帳交易的其他分類不算。分類的範圍由 `ledger/list.ts` 的
  `categoryFilterAccountIds` 決定,清單與摘要共用。
- **換算**:每條分錄用交易當天的匯率換成顯示幣別(`fx` 的 `convert`)。同一格(月份、分類、固定與否)先加總、再取整數,
  其他數字(各分類、各月、支出、收入、淨額)都是這些整數相加,畫面上的數字彼此對得上;期間摘要與每月報表用同一套格子
  (`server/reports/totals.ts`),同一段期間的數字一致。
- **缺匯率**:一筆交易缺任何一個匯率就整筆不算,`missingRate` 是筆數,畫面上標出來。
- **各分類**:依上層分組(上層的金額含子分類),上層與子分類各自依金額由大到小;金額為 0 的不列。比例是佔支出(或收入)合計的百分比。
- **筆數**(`transactionCount`):至少有一條分錄被加總的交易。
- 日期跟清單一樣以 UTC 切日。

## 每月報表

程式在 `server/reports/monthly.ts`(`monthlyReport`),API 是 `GET /api/finance/reports/monthly`,網址參數跟交易清單相同
(報表頁只送 `from`、`to`)。畫面是 `/finance/reports`(`components/ReportsPage.tsx`、`MonthlyChart.tsx`)。

- **月份**:期間內的每個月,含沒有交易的月份,以 UTC 切。沒給開始或結束時,用帳本第一筆或最後一筆交易的日期。
- 每月的支出(固定 / 變動)、收入、淨額,定義跟期間摘要相同;**合計**是各月相加,**每月平均**是合計 ÷ 月數、各自四捨五入
  (所以平均的淨額不一定剛好等於平均收入 − 平均支出)。各分類同期間摘要;分類表的每月平均也是 ÷ 月數。
- **期間**:過去 12 個月(含本月的 12 個完整月份,內建預設)、今年、去年、全部、自訂。「設為預設」存在瀏覽器的 localStorage。
- **長條圖**:固定在下、變動疊在上;退款多於支出的月份從 0 開始。最高的月份超過中位數 2.5 倍時,刻度上限改成中位數的 2.5 倍,
  超過的長條截斷、頂端畫斷裂記號並標出金額。滑過或聚焦顯示那個月的數字;點月份(長條或表格)→ 那個月的交易清單,
  點分類 → 那個分類、那段期間的交易清單。

## 淨資產與側欄的帳戶清單

程式在 `server/reports/net-worth.ts`(`getNetWorth`),API 是 `GET /api/finance/reports/net-worth`(沒有參數),
群組與帳戶的清單取自 `ledger/account-groups.ts`,餘額取自 `ledger/balances.ts` 的 `getAccountBalances`。
畫面在側欄(`components/SidebarAccounts.tsx`):欄頭是淨資產與可動用資金,下面是帳戶清單。

- **換算**:用今天(UTC)或之前最近的匯率(歷史報表才用交易當天的匯率)。缺匯率的帳戶不算進淨資產,`missingRate` 是帳戶數;
  所在群組的合計是 `null`(畫面顯示「—」)。
- **淨資產**:所有資產 / 負債帳戶的餘額合計(負債為負,含封存的帳戶)。
- **可動用資金**:子類型 `cash`、`bank`(流動性分類「現金及約當現金」)的合計。
- **群組**:依群組的順序,未分組的帳戶放在最後的「未分組」;群組內依帳戶的順序。群組合計用群組設定的幣別,沒設定用顯示幣別,
  各帳戶換算後加總再取整數。封存且餘額為 0 的帳戶不列。
- **畫面**:點帳戶 → `/finance/transactions?account=<id>`。整個帳戶區塊與每個群組都可以收合,預設群組收合(只看合計);
  狀態存在瀏覽器的 localStorage。換頁、或同一個分頁裡帳本改了(`lib/ledger-events.ts`:交易的新增 / 編輯 / 刪除、匯入套用、帳戶管理)
  就重新取。
